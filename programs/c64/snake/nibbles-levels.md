# Nibbles levels (inspiration)

Levels 1-9 of the classic QBasic Nibbles, redrawn as ASCII from `NIBBLES.BAS`
([QB64 mirror](https://git.qb64.dev/QB64/QB64-website/raw/branch/main/samples/nibbles/src/nibbles.bas),
[Wikipedia](https://en.wikipedia.org/wiki/Nibbles_(video_game))). Level 10+ is a variant of 8.

The original grid is 80 x 50 half-cells (`Set row, col`); here two rows are merged into one
text row, so each map is 80 x 25. Our snake field is 38 x 22 (cols 1-38, rows 2-23), so
these need scaling by about half. Wall `#`, floor `.`. The originals have two snakes with
per-level start positions; level 1 is empty.
